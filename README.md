**Author:**

---

## 🧠 Overview
**Fragments UI** is a lightweight front-end web application that allows users to create, view, and manage text fragments through a simple interface.  
It communicates with the [Fragments Microservice](https://github.com/AydinArif/fragments) backend using REST API calls and integrates **AWS Cognito** for secure authentication.

This project was developed as part of the **Cloud Computing for Programmers (BTI)** course to demonstrate front-end and back-end integration using modern JavaScript and containerization technologies.

---

## 🚀 Features
- 🔐 Secure login using AWS Cognito and `oidc-client-ts`
- 🧩 Create and view text fragments via the Fragments API
- ⚡ Built with Parcel for fast bundling and live reloading
- 🐳 Includes a Dockerfile and .dockerignore following Docker best practices
